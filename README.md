# Dailies releases

Signed Android builds of Dailies, a few small word games, new every day.
Free, offline, no ads.
Installed copies update themselves from here. In a browser:
https://dailies.matisseduffield.workers.dev

**[Download Dailies 2.13.0](https://raw.githubusercontent.com/matisseduffield/dailies-releases/main/Dailies.apk)**

On your phone: open the link, then open the downloaded file and allow
the install when Android asks. You only do this once; after that the app
offers updates itself.

## What's new in 2.13.0

- The home screen shows your last two weeks and how many days in a row you've played
